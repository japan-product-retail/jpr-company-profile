Security Lead: Ken Shimabukuro
Managing Member & Security Lead
JP Product Retail LLC

Ken Shimabukuro serves as the Security Lead for JP Product Retail LLC and is responsible for the company’s Security & Infrastructure function.

This function oversees defensive security, vulnerability management, secure development, infrastructure security, and incident response for systems owned or operated by JP Product Retail LLC.

The scope includes the company’s internal e-commerce automation systems, inventory management tools, APIs, servers, source code, and related internal infrastructure.

Security responsibilities

  • Defensive security analysis
  • Vulnerability identification and remediation
  • Secure code review
  • Patch validation
  • Infrastructure and API security
  • Incident response and security monitoring
